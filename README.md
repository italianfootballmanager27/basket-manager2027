# BASKET MANAGER 2027 — Alpha 1

Prima base tecnica mobile-first del progetto.

## Cosa contiene
- Menu iniziale con Manager Career e Player Career.
- Identità grafica dark blu notte/arancione.
- Prima configurazione delle due modalità.
- Salvataggio locale delle preferenze.
- Manifest PWA e service worker iniziale.

## Come provarlo
Per testarlo correttamente serve pubblicarlo su un hosting HTTPS, ad esempio GitHub Pages. Aprire `index.html` direttamente come file locale non abilita tutte le funzioni PWA.

## Pubblicazione con GitHub Pages
1. Crea un repository GitHub chiamato `basket-manager-2027`.
2. Carica il contenuto di questa cartella nella radice del repository.
3. Apri Settings → Pages.
4. In Build and deployment seleziona Deploy from a branch.
5. Scegli `main` e `/ (root)`, poi salva.
6. Attendi la pubblicazione e apri l'indirizzo GitHub Pages dal telefono Android.
7. Dal menu del browser scegli "Aggiungi a schermata Home" o "Installa app", se disponibile.

## Prossimi moduli
- Database di squadre, competizioni e giocatori.
- Selezione dei campionati e delle squadre.
- Stemmi e schede club.
- Calendari, classifiche e simulazione partite.
- Gestione società e carriera giocatore.

Nota: stemmi, fotografie e dati ufficiali saranno integrati soltanto usando fonti autorizzate o licenze compatibili.
